# STM32CubeIDE 移植说明

此处是协议核心的**移植接口说明**，尚未针对任何具体 STM32 板卡完成编译或实机验证。

1. 用 CubeMX 新建工程，开启一个 UART（推荐 9600 8N1）、FreeRTOS、一个 GPIO 输出控制 RS485 芯片的 DE/RE；在硬件层加 RS485 收发器并确认终端电阻和共地。
2. 把 `../core/modbus_slave.c/.h` 添加到工程。应用任务持有 `mb_slave_t`，地址设为 1。寄存器 0 存有符号温度 ×10（转为 `uint16_t` 位模式），寄存器 1 存湿度 ×10。寄存器 2、3 可作为状态和计数器。
3. UART 使用接收 DMA + IDLE/定时器判定完整 RTU 帧。校验帧长后调用 `mb_handle()`。有响应时，先拉高 DE，发送完整响应，**等待 UART TC（最后停止位完成）**再拉低 DE。中断只通知任务处理，不在中断里执行传感器读取和阻塞串口发送。
4. 采样任务更新寄存器时用临界区或互斥锁发布完整快照；Modbus 任务先复制寄存器快照，再调用协议核心，避免两次读取之间数据变化。
5. 根据芯片实际 UART/DMA 引脚配置补充 `board.c`、接线图和实机日志。不同 HAL 版本与 MCU 型号的回调细节不可直接假定相同。

网关本身部署于 Linux 主机，通过 USB-RS485 连接 STM32 从站；无需在 MCU 上移植 MQTT、SQLite 或 Python。
